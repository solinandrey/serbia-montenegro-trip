# Копилка · Белград и Черногория

Куда трое скидывают всё, что нужно под рукой в поездке: ссылки на жильё, точки в карте,
номера броней, телефоны хозяев, заметки и договорённости.

Живёт тут: **https://solinandrey.github.io/serbia-montenegro-trip/**

## Как начать

Открой ссылку с паролем — она подключит общий план и сама уберёт пароль из адресной строки:

```
https://solinandrey.github.io/serbia-montenegro-trip/#feed&key=ПАРОЛЬ
```

Пароль один на троих, спроси у Андрея. Он запомнится в браузере, вводить каждый раз
не нужно. Дальше нажми «Кто я» и подпишись — иначе в дороге не разобрать, чья правка.

## Три экрана

**Копилка** — лента. Сверху поле: вставь ссылку или напиши заметку. Первая строка станет
заголовком карточки, остальное — примечанием. Тут же выбери точку маршрута. Если сайт
отдаёт карточку, подтянется превью с картинкой и описанием; Airbnb и Booking закрыты
от этого, тогда просто останется ссылка.

Карточку можно закрепить — она уедет в ряд «Под рукой» наверху, откуда значение копируется
одним нажатием. Удобно для номера брони и кода от подъезда.

**Точки** — маршрут. Добавить точку, поправить даты, убрать лишнюю. Ссылки убранной точки
не пропадут, уедут в «Без точки».

**Кто что** — журнал: кто и когда правил, что добавил и что убрал. Откатить нельзя,
но на вопрос «кто это удалил» ответ есть.

## Что важно знать

Правки видят все трое, чужие подтягиваются сами раз в двадцать секунд и когда возвращаешься
во вкладку. Если двое пишут одновременно, ничего не затирается: сервер отдаёт свежую версию,
а страница сливает её с твоей.

Удалил по ошибке — внизу появится чёрная полоса «Вернуть», она живёт шесть секунд
и кладёт карточку обратно на то же место.

То, что появилось с твоего прошлого захода, помечено красным «ново», а в шапке у «Копилки»
висит счётчик. Метки не пропадают сразу — держатся, пока не уйдёшь со страницы.

На карточках две реакции: **✓** и **?**. Согласиться или задать вопрос, не уходя в телегу.
Наведи — увидишь, кто поставил.

Без пароля страница работает как блокнот: показывает исходный план из `plan.json` и хранит
правки только в твоём браузере. Строка внизу всегда честно пишет, в каком ты режиме.

## Структура plan.json

```jsonc
{
  "version": 2,
  "points": [ { "id": "sever", "title": "Север", "dates": "14 — 20 сен" } ],
  "links": [ {
    "id": "s03", "point": "sever",
    "title": "Жабляк: Чёрное озеро, кольцо вокруг Дурмитора",
    "note": "2–3 ночи",
    "url": "https://…", "num": "номер брони",
    "by": "Андрей", "ts": 1786987911858, "pin": false,
    "react": [ { "who": "Маша", "kind": "+1" } ]
  } ]
}
```

Обязательны только `id` и `title`. `point` — `null`, если запись ни к чему конкретному.
Ключи `checklist`, `segments` и `notes` остались от прежней структуры страницы, UI их
не читает, но удалять не надо: через них возможен откат.

## Что проверить перед выездом

Всё, что помечено датами и ценами, устаревает. Особенно:

- **Расписание поезда.** Дневной сезонный «Тара» ходит по 13 сентября, летний состав ночного
  «Ловчен» — по ночь с 13 на 14-е. Проверять на `srbijavoz.rs`, международные билеты онлайн
  не продаются.
- **Лимит безвизовых дней** — свой для каждого паспорта, у Сербии и Черногории счётчики разные.
- **Цены на аренду машины** — сентябрьские падают после 15-го, но зелёная карта на Албанию
  и Боснию оформляется только при бронировании.

## Для тех, кто трогает код

```bash
python3 -m http.server 8000   # http://localhost:8000
```

Двойным кликом `index.html` не откроется: браузер запретит читать `plan.json` с `file://`.
Правила проекта — в `CLAUDE.md`, читать целиком перед первой правкой. Сервер общего плана
лежит в `server/`, катится командой `cd server && railway up --service api`.
