# Београд → Црна Гора, сентябрь 2026

План поездки на троих: неделя с небольшим в Белграде, поезд до Бара, две недели по Черногории на машине.
Первая неделя в Черногории — свободная, вторая — рабочая.

## Что где лежит

| Файл | Что внутри | Кто правит |
|---|---|---|
| `plan.json` | Чеклист, пункты плана по отрезкам, заметки | все, через коммиты |
| `index.html` | Страница: вёрстка, профиль высот, справочные блоки | тот, кто трогает код |

Справочные факты (цены на поезд, правила регистрации, чего не делать с арендой) зашиты в `index.html`
в массиве `SEGMENTS`. Это то, что не меняется от нашего настроения — только при проверке актуальности.

## Как открыть

**GitHub Pages** — Settings → Pages → Deploy from a branch → `main` / root.
Через минуту страница живёт на `https://solinandrey.github.io/serbia-montenegro-trip/`.

**Локально** — открыть `index.html` двойным кликом не выйдет: браузер запретит читать `plan.json`
с `file://`. Нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Как вносить правки

Два пути, оба рабочие.

**Через гит (основной).** Правите `plan.json` руками, коммитите, пушите. Страница подхватывает
изменения при следующей загрузке. Конфликты решает гит, ничьи правки не теряются.

```bash
git pull
$EDITOR plan.json
git commit -am "Жабляк: три ночи вместо двух"
git push
```

**Через страницу (быстрый).** Добавляете пункты и заметки прямо в браузере, потом жмёте
«Скачать plan.json», кладёте файл поверх старого, коммитите. Удобно, когда сидишь в кафе
и хочешь дописать мысль, но правки других при этом можно затереть — сначала `git pull`.

## Структура plan.json

```jsonc
{
  "version": 1,
  "checklist": [ { "id": "c01", "text": "…", "done": false } ],
  "segments": {
    "beograd": [ { "id": "b01", "text": "…" } ],  // Белград
    "voz":     [ … ],                             // поезд Београд Центар → Бар
    "sever":   [ … ],                             // север Черногории, свободная неделя
    "more":    [ … ]                              // побережье, рабочая неделя
  },
  "notes": [ { "id": "n01", "segment": "sever", "author": "Андрей", "text": "…", "ts": 1757000000000 } ]
}
```

`id` — любая уникальная строка. `ts` — миллисекунды, `Date.now()`. Ключи в `segments` менять нельзя,
они привязаны к отрезкам в `index.html`.

## Что проверить перед выездом

Всё, что помечено датами и ценами, устаревает. Особенно:

- **Расписание поезда.** Дневной сезонный «Тара» ходит по 13 сентября, летний состав ночного «Ловћен» —
  по ночь с 13 на 14-е. Проверять на `srbijavoz.rs`, международные билеты онлайн не продаются.
- **Лимит безвизовых дней** — свой для каждого паспорта, у Сербии и Черногории счётчики разные.
- **Цены на аренду машины** — сентябрьские падают после 15-го, но зелёная карта на Албанию и Боснию
  оформляется только при бронировании.
