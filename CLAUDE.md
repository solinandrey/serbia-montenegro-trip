# CLAUDE.md

Контекст для работы над этим репозиторием. Читать целиком перед первой правкой.

## Что это

Копилка поездки на троих: Белград (2–13 сентября 2026), поезд Белград-Центр → Бар,
две недели по Черногории на машине. Первая неделя в Черногории свободная, вторая рабочая —
двое из троих работают удалённо днём в будни.

Не лендинг и не путеводитель. Рабочий документ, в который втроём скидывают ссылки, номера
броней, телефоны и заметки. Ценность — в конкретике: суммы, времена, названия, «сюда
не суйся». Всё, что звучит как текст турагентства, из проекта вырезается.

Все названия по-русски: Белград, Черногория, Ловчен, Жабляк, Никшич.

## Файлы

```
index.html    вёрстка, стили, вся логика
```

## Запуск

```bash
python3 -m http.server 8000   # http://localhost:8000
```

Через `file://` не работает: браузер блокирует `fetch('plan.json')`. Продакшн — GitHub Pages
из ветки `main`, root.

## Три экрана

Страница — не свиток, а три экрана, между которыми переключает шапка. Одновременно виден
ровно один, остальные скрыты атрибутом `hidden`.

1. **Копилка** (`#feed`) — поле ввода, закреплённые карточки, фильтр по точкам, лента.
2. **Точки** (`#points`) — маршрут: добавить, поправить даты, убрать.
3. **Кто что** (`#log`) — журнал правок с сервера.

**Две раскладки, обе из прототипа.** До 1040 px — телефонная: экраны переключаются
и видны по одному. От 1040 px включается раскладка ноутбука: три колонки в одной белой
рамке — слева точки маршрута списком и «+ новая точка», по центру поле ввода и лента
сеткой `repeat(auto-fill,minmax(310px,1fr))`, справа «Под рукой» и «Что менялось».
На ноутбуке журнал живёт в правой рельсе постоянно, поэтому вкладка «Кто что» там прячется,
а центр делят лента и точки.

Фильтры и закреплённые рисуются в оба места сразу (`filters` и `filtersDesk`,
`pinned` и `pinnedDesk`) — так не нужно перестраивать DOM при смене ширины. Смену
брейкпоинта ловит слушатель `resize`, который перерисовывает всё только когда ширина
реально перешла границу.

**Чёрной шапки нет.** Была, убрана: переключатель экранов, строка «кто правил последним»
и кнопка «Кто я» живут в левой колонке. Фон белый на всю ширину, серой подложки и рамки
вокруг рабочей области тоже нет — просили убрать.

**Имена классов проверять на совпадение.** Дважды наступили: модификатор `.top` внутри
рельсы совпал с классом чёрной шапки (чёрное на чёрном), а `.who` в строке журнала —
с кнопкой «Кто я» (имена в красных пилюлях). В журнале класс теперь `.author`.

**Хеш составной.** `parseHash()` режет его по `&`: одна часть — экран, другая — `key=…`
с общим паролем. Ссылка `#feed&key=ПАРОЛЬ` открывает ленту и подключает общий план.
Пароль забирается в `takeKeyFromHash()` до первого `load()` и сразу вычищается из адреса
через `history.replaceState`. Только хеш, не query: query уезжает в логи хостинга.

## Модель данных

```jsonc
{
  "version": 2,
  "points": [ { "id": "sever", "title": "Север", "dates": "14 — 20 сен" } ],
  "links":  [ {
    "id": "…", "point": "sever",      // null — «Без точки»
    "title": "…",                     // первая строка ввода, она же заголовок карточки
    "note": "…",                      // остальное, необязательно
    "url": "https://…",               // есть url — карточка ссылка, нет — заметка
    "num": "HMQ4T8Z",                 // копируется по нажатию: бронь, код, номер
    "phone": "…", "address": "…",     // необязательно
    "by": "Маша", "ts": 1786987911858,
    "pin": true,                      // «под рукой», ряд карточек сверху
    "react": [ { "who": "Андрей", "kind": "+1" } ]   // +1 и ?
  } ],
  "checklist": [], "segments": {}, "notes": []       // прежняя модель, UI её не читает
}
```

**Старые ключи не удалять.** `checklist`, `segments` и `notes` остались от прежней
структуры и лежат нетронутыми: из них сделана миграция, и через них возможен откат.

**Миграция.** `migrate()` срабатывает один раз, когда в плане нет `points`: отрезки
становятся точками, пункты плана, чеклист, заметки и справочные факты — карточками ленты.
Факты зашиты в массив `FACTS` в `index.html`; это проверенные числа, а не рыба.

**Порядок в `prep()` критичен:** `normalize(migrate(p))`, не наоборот. `normalize()`
подставляет `points` по умолчанию, и если пустить его первым, `migrate()` решит, что
переезд уже сделан, и лента окажется пустой. Так уже ломалось.

**Новый ключ верхнего уровня добавляется в четырёх местах:** `mergePlan()` и `normalize()`
в `index.html`, `validPlan()` на сервере, `plan.json`. Пропустишь `mergePlan()` — данные
молча исчезнут через 20 секунд при первом `pullShared()`. Проверку на сервере писать мягко
(«если поле есть, оно массив»), иначе сервис начнёт отвергать планы, которые сам же отдал.

## Откуда берётся план

Четыре источника, страница перебирает их сверху вниз:

1. **Общий план на сервере.** Основной режим. Пароль в `trip:key`, план в Postgres.
2. **Артефакт Claude.** Если есть `window.storage`.
3. **localStorage браузера.** Сервер недоступен или пароль не введён.
4. **`plan.json` из репозитория.** Исходный слепок, он же засев пустой базы.

`sessionStorage` не использовать.

## Сервис

```
server/index.js        GET /plan, PUT /plan, GET /history, GET /history/:rev, GET /og, GET /health
server/plan.seed.json  копия plan.json, засевает пустую базу
```

Railway, проект `balkan-trip-api`, сервисы `api` и `Postgres`. Адрес
`https://api-production-aa10.up.railway.app` захардкожен в `index.html` (константа `API`).
Переменные: `TRIP_PASSWORD`, `ALLOW_ORIGIN`, `DATABASE_URL`.
Деплой: `cd server && railway up --service api`.

**Ревизии — не украшение.** `PUT` принимает номер ревизии, который клиент прочитал. Если
кто-то записал раньше, сервер отвечает `409` и текущим планом; клиент сливает и повторяет.
Удалённое в сессии держится в `tomb`, иначе слияние воскрешает удалённое.

**Реакции сливаются отдельно.** `mergeList()` при совпадении `id` берёт свою версию
элемента — для текста верно, для реакций это потеря: двое жмут «+1» одновременно, и одна
реакция исчезает. `mergeItem()` объединяет `react` по паре (`who`, `kind`). Главное место,
где фича тихо не работает; проверять двумя окнами.

**Таблицы три.** `plan` — текущее состояние. `plan_rev` — снимок на каждую удачную запись,
последние 50. `og_cache` — карточки ссылок на неделю. Все создаются в `init()` через
`if not exists`: сервис катится в работающую базу.

**`/og` ходит по чужой ссылке от имени сервера**, поэтому `safeTarget()` пускает только
http/https наружу и режет localhost, `.internal`, `.local` и приватные диапазоны. Убрать
проверку — открыть сервер для похода внутрь инфраструктуры. Многие сайты карточку не отдают
(Airbnb возвращает редирект, Booking закрыт) — это норма. Превью рисуется, только если
пришли картинка или описание.

Репозиторий публичный, адрес API виден в исходнике. Защита — пароль, он же на чтение.
Менять: `railway variables --service api --set TRIP_PASSWORD=…`.

## Оформление

Собрано по прототипу из Claude Design (`Копилка.dc.html`, август 2026). Токены в `:root`:

```
--acc  #E8000D    --ink #000       --paper #E6E4E1   --surf #F5F3F1
--hair rgba(0,0,0,.14)   --edge rgba(0,0,0,.2)   --dim rgba(0,0,0,.52)
```

Шрифты: **Oswald** капслоком на заголовки, **Golos Text** на текст, **JetBrains Mono**
на числа, домены и даты. Все три несут кириллицу — при замене шрифта проверять это первым
делом, иначе страница падает в системный (у Space Grotesk кириллицы нет).

Формы: карточки белые, рамка `rgba(0,0,0,.18)`, радиус 16. Чипы — пилюли `999`, чёрные
когда активны. Кнопки — радиус 10–12, чёрные, красные когда есть что сохранять. Шапка
липкая, чёрная, с красной чертой снизу.

Тема одна и светлая. `prefers-color-scheme: dark` в файле нет и заводить не надо: тёмную
дважды просили убрать.

## Движение

Из прототипа: `arrive` (карточка влетает с перелётом), `flash` (красная вспышка у новой),
`pop` (пружинка на реакции и закреплении), `dot` (пульс живого индикатора), `toastUp` + `bar`
(тост отмены с убегающей полосой). `prefers-reduced-motion: reduce` гасит всё.

## Тон текстов

Пишем как местный, который объясняет знакомому за столом. Прямо, с мнением, с цифрами.

Так: «Внутри старого Котора не селиться: акустика колодца, бары до трёх, машину девать некуда.»
Не так: «Старый город Котора подарит незабываемую атмосферу.»

Кнопки и подписи — активным залогом, тем же словом на всём пути действия. Пустое состояние —
приглашение, а не извинение.

## Что нельзя ломать

- Удаление всегда с отменой: тост живёт 6 секунд и возвращает карточку на то же место.
- Клавиатурная достижимость: все действия кнопками, `:focus-visible` виден.
- Мобильная вёрстка: страница делалась под телефон, 430 px — основная ширина.
- `prefers-reduced-motion` уважается.
- Числа в карточках из `FACTS` — проверенные факты, меняются только с проверкой источника.
- Порядок `normalize(migrate(p))` в `prep()`.

## Что устаревает и требует проверки

- **Поезд.** Дневной сезонный 1131 «Тара» ходит по 13 сентября 2026, летний состав ночного
  433 «Ловчен» — по ночь с 13 на 14-е. Источник `srbijavoz.rs`. Перепроверить в конце августа.
- **Цены билетов.** 23,80 € второй класс, 35,60 € первый, резервация 3 €, кушет 8–12 €.
- **Безвизовые дни.** Свои для каждого паспорта, счётчики Сербии и Черногории независимы.
- **Аренда машины.** 25–40 €/сут в сентябре; зелёная карта на Албанию и Боснию оформляется
  только при бронировании.
