# CLAUDE.md

Контекст для работы над этим репозиторием. Читать целиком перед первой правкой.

## Что это

Страница-план поездки на троих: Белград (2–13 сентября 2026), поезд Београд Центар → Бар,
две недели по Черногории на машине. Первая неделя в Черногории свободная, вторая рабочая —
двое из троих работают удалённо днём в будни.

Не лендинг и не путеводитель. Рабочий документ, который правят втроём во время поездки.
Ценность страницы — в конкретике: суммы, времена, названия, «сюда не суйся». Всё, что звучит
как текст турагентства, из проекта вырезается.

## Файлы

```
index.html    вёрстка, стили, вся логика; справочные блоки в массиве SEGMENTS
plan.json     данные: чеклист, пункты плана по отрезкам, заметки
README.md     инструкция для людей: как открыть, как править, что проверить перед выездом
```

Сборки нет, зависимостей нет, npm не нужен. Три файла, ванильный JS, шрифты с Google Fonts.

## Запуск

```bash
python3 -m http.server 8000   # http://localhost:8000
```

Через `file://` не работает: браузер блокирует `fetch('plan.json')`. Продакшн — GitHub Pages
из ветки `main`, root.

## Модель данных

`plan.json` — единственный источник правды для изменяемого содержимого:

```jsonc
{
  "version": 1,
  "checklist": [ { "id": "c01", "text": "…", "done": false } ],
  "segments": {
    "beograd": [ { "id": "b01", "text": "…" } ],
    "voz":     [ … ],
    "sever":   [ … ],
    "more":    [ … ]
  },
  "notes": [ { "id": "n01", "segment": "sever", "author": "…", "text": "…", "ts": 1757000000000 } ]
}
```

Ключи `beograd` / `voz` / `sever` / `more` захардкожены в `SEGMENTS` внутри `index.html`.
Переименование ключа ломает связь плана с отрезком — если добавляете отрезок, добавляйте
в оба места одним коммитом.

Функция `seed()` в `index.html` дублирует стартовые данные на случай, когда `plan.json`
не прочитался. При правке `plan.json` она расходится с ним, и это нормально: `plan.json`
всегда выигрывает, когда доступен.

## Два режима загрузки

Страница живёт в двух средах, обе нужно держать рабочими:

1. **Репозиторий.** `window.storage` нет, план читается из `plan.json`, правки в памяти вкладки,
   выгрузка кнопкой «Скачать plan.json» → коммит.
2. **Артефакт Claude.** `window.storage` есть, состояние в общей памяти по ключу
   `trip:beograd-crnagora:v1`, правки видны всем по ссылке.

`localStorage` и `sessionStorage` не использовать — в артефактах они не работают и всё падает.
Персональное (имя автора заметок) — `window.storage` с `shared:false`, общее — `shared:true`.

## Дизайн-токены

Определены в `:root`, новые цвета не вводить без причины:

```
--ink #16232A   --limestone #E6E4DC   --card #F2F1EB
--sea #0E5A61   --signal #F0B429      --alarm #A8382B   --sage #8C9A92
```

Шрифты: Archivo (заголовки, расширенное начертание, капслок), IBM Plex Sans (текст),
IBM Plex Mono (всё числовое: времена, цены, высоты, даты, километры). Правило простое —
если это число или код, оно моно.

Носитель идеи — профиль высот в шапке: сплошная линия сегмента поезда, пунктир машины,
подписи высот. Это не декорация, а содержание: маршрут дважды поднимается на километр
и дважды падает к морю. Не заменять на дженерик-карту или иконки.

Углы прямые, `border-radius: 0` по всему проекту. Градиентов и теней нет, кроме заливки
под профилем высот. Анимаций почти нет и добавлять их не надо.

## Тон текстов

Пишем как местный, который объясняет знакомому за столом. Прямо, с мнением, с цифрами.

Так: «Внутри старого Котора не селиться: акустика колодца, бары до трёх, машину девать некуда.»
Не так: «Старый город Котора подарит незабываемую атмосферу.»

Кнопки и подписи — активным залогом, тем же словом на всём пути действия. «Скачать plan.json»,
а не «Экспорт». Пустое состояние — приглашение, а не извинение.

## Что нельзя ломать

- Числа в справочных блоках (`SEGMENTS[].facts`) — это проверенные факты, а не рыба.
  Меняются только вместе с проверкой источника, в коммите указывать откуда.
- Клавиатурная доступность: `:focus-visible` с жёлтым контуром, все действия достижимы табом.
- Мобильная вёрстка: сетка отрезков схлопывается в одну колонку на 720px, кнопки правки
  на тач-устройствах видны всегда (`@media (hover:none)`).
- `prefers-reduced-motion` уважается.

## Что устаревает и требует проверки

- **Поезд.** Дневной сезонный 1131 «Тара» из Белграда ходит по 13 сентября 2026,
  летний состав ночного 433 «Ловћен» — по ночь с 13 на 14-е. Источник `srbijavoz.rs`.
  Сезонные рейсы иногда снимают раньше объявленного — перепроверить в конце августа.
- **Цены билетов.** 23,80 € второй класс, 35,60 € первый, резервация 3 €, кушет 8–12 €.
- **Безвизовые дни.** Свои для каждого паспорта, счётчики Сербии и Черногории независимы.
- **Аренда машины.** 25–40 €/сут в сентябре; зелёная карта на Албанию и Боснию оформляется
  только при бронировании, не после.
